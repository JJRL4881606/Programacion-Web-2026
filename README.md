## Organización del repositorio

El contenido se organizará mediante carpetas y archivos para facilitar la consulta y el seguimiento de las actividades realizadas durante el semestre.

1. Cada actividad tendrá su propia carpeta cuando sea necesario.
2. Los ejercicios, prácticas y proyectos se organizarán de acuerdo con su contenido.
3. Los archivos incluirán nombres claros para identificar fácilmente cada actividad.
4. Cuando sea relevante, se incluirá la fecha correspondiente a cada trabajo.
5. Las nuevas actividades se agregarán al registro de trabajos conforme sean realizadas.
