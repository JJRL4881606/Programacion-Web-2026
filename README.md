## Contenido del repositorio

El repositorio se organiza mediante carpetas para facilitar la consulta y el mantenimiento de las actividades realizadas durante el semestre.

Las actividades pueden incluir:

- Ejercicios de programación web
- Prácticas
- Trabajos
- Proyectos
- Código fuente y recursos relacionados

Cada actividad deberá incluir, cuando corresponda, su **nombre** y **fecha de realización**.

## Organización

Para mantener el repositorio ordenado, se seguirá una estructura similar a la siguiente:

1. Crear una carpeta para cada ejercicio, práctica, trabajo o proyecto.
2. Utilizar nombres claros y descriptivos para identificar cada actividad.
3. Incluir dentro de cada carpeta los archivos correspondientes a la actividad.
4. Registrar las actividades realizadas en la tabla de seguimiento.
5. Mantener actualizada la estructura conforme avance el semestre.
